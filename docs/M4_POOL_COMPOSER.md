## Source compiler corrective Gauntlet

The first attempted internal `get_vbox()` routing in commit dbc65e3 was **NOT a valid ConfirmationDialog API** in Godot 4.6; [focused #38161079655](https://github.com/xxiamadelxx-blip/dice-metal-barbie/actions/runs/38161079655) correctly failed GDScript compilation with `Function "get_vbox()" not found in base self`. The method is supplied by `FileDialog`, not `ConfirmationDialog`. Root-size behavior: `Window.wrap_controls` can automatically grow dialogs beyond viewport when autowrapped child controls demand a larger minimum; as originally captured in the genuine 720×1280 native video, the footer disappears. **Next fix uses the documented Window property** `wrap_controls = false` before adding the bounded column, keeps the original native `ConfirmationDialog` + its genuine cancel/confirmed signals intact, and retains the mobile upper bounds and source-frame geometry checks. Previous invalid-method commit FAIL is not reinterpreted as pass; fresh exact-source compile+native 24fps Android QA is required.
