## Direct verified Alpha 4 architecture

Actually retrieved user's exact **16,646,991-byte** `AdelDiceRoll_ALPHA_4_0_0_LIVE(1).html` from user personal Library and inspected the original source locally, not guessed. Header `Adel Dice Roll · Alpha 4.0.0 Live · Obsidian Studio`, loads **Three.js r184 / 0.184.0**; scene `THREE.Scene`, `new THREE.WebGLRenderer` with **WebGL2**, original physically shaded obsidian `THREE.MeshPhysicalMaterial` with base PBR atlases, roughness/normal maps and clearcoat; ACES Filmic tonemapping, CSS+JS mobile interface.

**Important difference from our real Jolt semantics:** Alpha 4 chooses actual dice result using Web Crypto rejection sampling, stores predetermined `d.target`, animates user-visible geometry with JavaScript pseudo-ballistic collision and ultimately performs `d.result=d.target` plus animated `faceToViewer` quaternion. It is visually elaborate, but the physical upward face does not authoritatively determine the chosen random outcome; DO NOT copy this mechanic as a "real physics" implementation. Other `Alpha 3` and `Alpha 4.1` builds are distinct and must not be conflated.

Alpha 4 uses jsDelivr for Three.js `three@0.184.0` on uncached first load, so raw HTML **is not guaranteed offline**. For a standalone Android install we bundle r184 ESM code at APK build time; no CDN, no Internet permission.

## Why this experiment matters

Not a generic search for "best engine": same exact model and physically authored gold, source BlenderKit PBR, approved strict overhead camera, same lighting geometry, matching tone/exposure/resolution to the extent permitted by separate PBR implementations and **same real Android GPU** are the needed A/B conditions. Browser software FPS vs Godot desktop Mesa FPS is **NOT a fair hardware ranking**. This branch currently contains real Chrome WebGL2 source and compiled Android debug APK. The original Alpha 4 UI is a separate design source, not automatically identical to the small benchmark UI.

**Gates open:** genuine exact private 500k premium GLB on Three WebView and Filament native Android hardware; Android AVD actual WebView picture; physical dice outcome determined by real physics not Alpha4 predetermined `d.target`; 1d20+2d6 rerolls; frame stability memory thermals on OnePlus Nord3; original material artistic signoff and 20-face visual checks; Filament native APK smoke.
