# M4 editable physical dice pool (candidate, approved functional scope)

The approved Alpha 3 reference has die palette, add/remove groups, count +/- and modifier +/- but its fake/WebGL fallback physics must NOT be copied. The project remains **offline Godot 4.6.3 / Jolt**, strict overhead Concept 3, M4 active. This code introduces a user-triggered **НАБОР** button INSIDE the existing formula input's original 46-pixel row, preserving all proven Android AVD coordinate targets for formula, physical throw, selected physical source reroll and history.

- The existing upper-left concealed advanced menu still starts hidden. Clicking the 44+px **НАБОР** control opens a true `ConfirmationDialog` editor with current manually typed real formula parsed by `RollFormula.parse`. The editor displays scrollable chosen signed physical die groups and provides add D4/D6/D8/D10/D12/D20/D100, remove, quantity +/-1, group sign +/- and signed modifier +/-1. No outcome is generated or guessed. Every candidate composition is validated using the same production formula parser with 12 groups, 64 physical dice and +/-10000 modifier bounds.
- All actions remain **draft-only** until explicit `ПРИМЕНИТЬ`. Cancel never alters the original formula; invalid existing manually typed expressions are rejected, NOT erased. On Apply the validated canonical expression goes into the original `PhysicalFormulaInput`; only tapping the original `БРОСИТЬ ФОРМУЛУ` starts authentic concurrent Jolt bodies and persistent history. During throw the modal and editor trigger lock.
- The initial minimal mobile HUD and approved obsidian visual/materials are unchanged; this is a functional M4 editor, not M5 artistic signoff.

Focused acceptance test `tests/m4_pool_editor_ui.gd` checks real Godot Controls and actual button signals, no last-die deletion, signed group totals, original text on cancel, applying a four-body formula, genuine concurrent physical Jolt settlement and saved offline result. No numerical physical sample is fabricated. Full same-SHA AVD/Blender/FFmpeg and independent critic are required after integration into PR #23. No on-phone FPS/upgrade claim.
